# Paty Lu Make Up — Guanajuato

Sitio responsive de portafolio, servicios, paquetes, contacto y solicitudes de cita.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

La carpeta de salida es `dist/`.

## Cloudflare Pages
- Framework: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Rama de producción: `main`
